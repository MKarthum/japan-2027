Personvern

En offentlig plan uten private reisedetaljer

Siden inneholder generell planleggingsinformasjon om rute, steder, mat, priser og aktiviteter. Opplysninger som kan identifisere eller lokalisere reisende hører ikke hjemme her.

Navn på reisende, kontaktinformasjon, hjemmeadresse, bookingreferanser, passdata, betalingsdata, eksakte flydetaljer og hotellreservasjoner publiseres ikke.

Hva kan være offentlig?

Greit

  • Planlagte reisevinduer
  • Forslag til byer og attraksjoner
  • Generelle budsjettanslag
  • Offentlige kilder
  • Spill-, film- og matforslag

Ikke greit

  • Bookingreferanser og billetter
  • Eksakte flytider og rominformasjon
  • Navn, telefon, e-post eller privat adresse
  • Pass-, betalings- eller forsikringsdata
  • Private dokumenter og kvitteringer
