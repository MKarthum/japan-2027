Offentlig repo

Ingen private data

Denne nettsiden og GitHub-repoet er offentlige. De skal være nyttige som reiseplan, men ubrukelige som kilde til private eller sikkerhetssensitive opplysninger.

Aldri publiser navn på reisende, kontaktinformasjon, hjemmeadresse, bookingreferanser, passdata, betalingsdata, eksakte flydetaljer, hotellreservasjoner eller annen informasjon som kan brukes til å identifisere eller lokalisere privatpersoner.

Hva kan være offentlig?

Greit

  • Foreløpige reisevinduer
  • Forslag til byer og attraksjoner
  • Generelle budsjettanslag
  • Offentlige kilder
  • Spill-, film- og matforslag

Ikke greit

  • Bookingreferanser og billetter
  • Eksakte flytider og rominformasjon
  • Navn, telefon, e-post eller adresse
  • Pass-, betalings- eller forsikringsdata
  • Private dokumenter og kvitteringer
